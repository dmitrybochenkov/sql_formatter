## B10.2a

- Единый `formatter_dialect.select_config` для runtime и CP01–CP05. Положительный
  выбор процедуры выполняется по lexer-токенам; литералы/комментарии не являются
  заголовками. Обычный SQL сохраняет штатный Teradata-диалект.
- Копия грамматики B10.1 получает проектный FluffConfig. Ни реестр диалектов,
  ни установленная SQLFluff не изменяются; карта смещений B6 сохранена.
- INSERT SELECT подключён к существующему узкому AST layout; граница INSERT/SELECT
  теперь явная. DELETE использует тот же безопасный обработчик WHERE, включая литералы.
- Исправлены воспроизводящие тесты B10.1: теперь они требуют идемпотентности INSERT
  и отсутствия E002 у DELETE, а не фиксируют известный дефект.
- На границе коммита a layout процедур намеренно ещё закрыт; DBeaver возвращает
  исходные байты. В b этот временный барьер заменяется транзакцией процедуры.
